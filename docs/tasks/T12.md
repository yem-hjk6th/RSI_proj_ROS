# Task T12: multi-layer (walls) variant

## Goal
Port the walls variant of the legacy pipeline (`legacy/realtime_cl_261023_ml/`) so that the wall programs
`usr_ELP_W4L28_*` can run through the ROS graph. Lower priority than T10 and T11: do it only after both are merged.

## Background
- `legacy/realtime_cl_261023_ml/README.md` lists the five changed modules and what changes: the `z_off` column and
  multi-layer gate of the readout, `veff_at_s(pass_only)`, the `sources` filter of the law (walls: only `elp`
  steers), the wall stop rule (`--sat-stop-s`).
- Single-layer patterns (no `z_off` column) must behave exactly as now: the existing golden tests stay green.
- No logged wall session is in this repository.

## Deliverables
- `width_readout_elp`: the `z_off` pattern handling and the multi-layer gate.
- `cl_controller`: `control_sources`, `sat_stop_s` (default 2.0 s on wall patterns, 0 otherwise, as in `run_cl.py`),
  the latch into forced open loop; `CtrlRecord` carries the new state if the legacy `ctrl` CSV does.
- The three wall patterns in `src/cl_controller/patterns/`.
- `krc_sim`: run a wall pattern (layers, +X and -X passes) so the tests below have input.

## Acceptance tests
1. All existing golden tests unchanged.
2. Synthetic golden: the legacy `_ml` modules and the port on the same `krc_sim` run of `W4L28_CL` with synthetic
   frames or widths: same gate decisions, legs, layer offsets and override sequence.
3. The wall stop rule: OvCmd at `ov_max` for `sat_stop_s` on a seen leg of layer >= 2 -> forced open loop, latched;
   not on layer 1, not on single-layer patterns.

## Out of scope
- Printing walls; tuning the rule.
