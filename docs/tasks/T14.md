# Task T14 (GitHub issue #35): angle failure map tool and the path geometry package

## Goal
A pure-Python tool that turns the logs of one print into the angle failure map of the four cameras (bore1, bore2,
ELP-A, ELP-B): four tables and figures, with every reading placed at the local tangent angle **where the camera
looked**. It is the data for retraining the borescope heads and for choosing the angle range each camera may steer.

The task also adds the package `src/path_geometry`, the pattern geometry of the fan and semicircle programs. T13 builds
its gates on it.

## Background
- `legacy/realtime_cl_cage2_semi_261103/README.md`: the geometry, the gates, and **known issue 1**.
- `legacy/realtime_cl_cage2_semi_261103/semi_failure_map_261103.py`: the legacy tool. Its four tables are
  `failuremap_bore_`, `failuremap_elp_`, `failuremap_elpframes_` and `failuremap_summary_<ses>.csv`.
- Geometry: `semi_geom.py` (`Piece`, `PathLine`, `SemiLines`, `SemiPattern`) and `fan_geom.py` (`Line`, `FanLines`,
  `FanPattern`) in the same folder; the patterns are in its `pattern/`.
- Data: `data/arc2ol_20261103_235936/` (ARC2, `"geometry": "semi"`) and `data/fan1cl_20261103_222754/` (FAN1,
  `"geometry": "fan"`); see `data/README.md`. The lab's own summary of ARC2-OL is
  `data/arc2ol_20261103_235936/roboter/failuremap_summary_20261103_235936_lab.csv`.
- **Known issue 1:** the legacy summary bins the ELP frames by the angle at the nozzle tip. The ELP reads 12–25 mm
  behind the tip, 35–111 deg of turn earlier on the ARC2 lobes, so those rows are binned at the wrong angle. A lab
  conclusion drawn from them was withdrawn. The per-row ELP table already has the right columns (`obs_*` at each row's
  `s_dep`).

## Deliverables
1. **`src/path_geometry`** (new, `ament_python`; numpy only; no ROS import). One interface for both geometries:
   - load a pattern json and its segs csv (`"geometry": "semi"` or `"fan"`; anything else → `ValueError`);
   - lines by `(kind, leg)` with `name`, `L`, `project(P) -> (s, e)`, `delta_at(s)`, `curv_at(s)`, `R_at(s)`,
     `lobe_at(s)`, `t_at(s)`, `n_at(s)`, and `locate(P, kinds)`;
   - straight fan lines: `curv` 0, `R` inf, `lobe` 0, `delta` = the line's `delta_deg`;
   - the legacy sign conventions (README "Geometry and gates") and the legacy load-time checks of the segs csv.
   - Copy the FAN1 and ARC2 pattern json + segs csv (+ the ARC2 chord list) into `src/path_geometry/patterns/`,
     byte-identical to `legacy/realtime_cl_cage2_semi_261103/pattern/` (a test checks this).
2. **`angle_failure_map`** (console script of `path_geometry`):
   `angle_failure_map --session data/<dir> [--pattern P] [--out DIR] [--bin 15] [--plots]`. It reads the session
   layout of `data/` (`.csv` or `.csv.gz`) and finds the pattern from `session_meta.json` (`realtime.pattern`) by file
   name in `src/path_geometry/patterns/`.
   - `failuremap_bore_<ses>.csv`, `failuremap_elp_<ses>.csv`, `failuremap_elpframes_<ses>.csv`: the legacy tables,
     with the same columns and rows.
   - `failuremap_summary_<ses>.csv` with a new column `basis`:
     - `obs`, bores: as legacy (bin `obs_delta`; group by cam, bin, `obs_curv`, `obs_R`; `n`, `bore_pushed`,
       `bore_sd_med`, `w_med`).
     - `obs`, ELPs (**changed**): every stored ELP row binned by its own `obs_delta`; group by cam, bin, `obs_curv`,
       `obs_R`; `n` = stored rows, `n_frames` = distinct frames, `w_med`, `w_q25`, `w_q75`.
     - `tip_frames`, ELPs: the legacy frame-availability rows (`elp_frames_with_rows`, `elp_rows_med`, binned by
       `tip_delta`), kept for comparison and labelled as such. A frame has no single observed angle.
   - `--plots`: one PNG per camera, x = bin centre (deg), y = bore pushed fraction (bores) or ELP row median width
     with the quartiles (ELPs), one line per (curvature sign, R). Figures are written at run time; none are committed.
3. **Tests** in `src/path_geometry/test/` (pytest; CI must pass). If the CI workflow lists packages, add the new one.

## Acceptance tests
1. **Geometry = legacy.** For the ARC2 and FAN1 patterns: on every ARC2 chord vertex and on at least 10 000 random
   points within 2 mm of the legs, `project`, `delta_at`, `curv_at`, `R_at`, `lobe_at`, `locate` equal the legacy
   `semi_geom` / `fan_geom` classes (floats within 1e-9, ints and names exactly).
2. **ARC2-OL golden.** Run the legacy `bores`, `elps` and `summary` of `semi_failure_map_261103.py` on
   `data/arc2ol_20261103_235936/` (decompressed into the legacy layout in a temp dir) and keep the result as a fixture
   (gzip, or a sha256 of a canonical CSV for the large tables; nothing over 5 MB). The port's bore, ELP-row and
   ELP-frame tables equal it (floats within 1e-9, the rest exactly). The `obs` bore rows and the `tip_frames` ELP rows
   of the port's summary equal the legacy summary. The `obs` ELP rows equal the groupby above applied by the test to
   the legacy ELP-row table.
3. **The data and the legacy tool agree.** The legacy summary of test 2 equals the lab's
   `failuremap_summary_20261103_235936_lab.csv` (to the CSV's printed precision). Checked before publication: the
   legacy tool on this data reproduces the lab's four tables byte for byte (196 summary rows, 3224 bore frames, 63 865
   ELP rows, 7694 ELP frames).
4. **Gate-log cross-check (ARC2-OL).** Joined on (cam, t) with `semi_gate_*.csv`, the bore rows' `obs_delta` is within
   0.01 deg of the log's `delta_obs`: the log prints two decimals, and `s_dep` in `bore*_rt` three (0.0005 mm is
   0.002 deg on R 12.917). The legacy tool gives 3224 matched frames, max 0.007 deg.
5. **FAN1-CL.** All four tables are produced; every row's `tip_delta` and `obs_delta` equals its line's `delta_deg`.
6. The figures are produced in a test (temp dir) and are non-empty.

## Out of scope
Training; new data; ROS nodes; the controller.
