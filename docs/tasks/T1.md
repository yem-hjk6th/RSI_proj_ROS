# Task T1 (GitHub issue #1)

## Goal
Port the RSI side of the PC to ROS 2 and build a controller simulator so everything can be tested without hardware.

## Deliverables
- **`src/krc_sim`** (ament_python): a fake KR C4 RSI client.
  - Sends one packet every 4 ms in the XML format the real controller uses. Take the format from `legacy/realtime_cl_261023/rsi_ov_listener.py` and `legacy/krc_config/rsi/RSI_MIN.rsi.xml` / `RSI_EthernetConfig.xml`.
  - Moves the TCP along a pattern json at programmed speed × override.
  - Counts late or missing replies (IPOC mismatch) and stops after the Timeout (100), like the controller.
  - Replay mode: streams `data/e1_20261022_165128/roboter/rsi_data_*.csv.gz`.
- **`src/krc_rsi_bridge`** (ament_python): the RSI UDP server.
  - Port the logic of `rsi_proc.py`, `rsi_ov_listener.py` and `rsi_ring.py`.
  - The reply loop runs in its own process and never waits on ROS. The ROS side talks to it through shared values or a queue.
  - Publishes `krc_interfaces/KrcState` on `/krc/state`.
  - Subscribes to `krc_interfaces/OverrideCmd` on `/krc/override_cmd`, with `seq` as the heartbeat.
  - Keeps every legacy safety behaviour (see the Safety invariants in `CLAUDE.md`):
    - clamp and speed floor;
    - `ov_outside` outside the print window;
    - forced latch;
    - watchdog with a linear ramp over `fallback_ramp_s`;
    - RKorr always 0.
  - All network values are ROS parameters, with placeholders in `config/example.yaml`.

## Acceptance tests (pytest, no hardware)
1. **Reply format:** for a given received packet and OvCmd, the reply is byte-identical to the legacy reply builder's output.
2. **Watchdog:**
   - With no commands, the override ramps to `ov_default` over `fallback_ramp_s`.
   - A stale heartbeat triggers the ramp, and a fresh heartbeat ends it.
3. **Clamp:** values outside `[ov_min, ov_max]` or below the floor are clamped.
4. **Round trip:** bridge and simulator on localhost for 20 s with zero timeouts. Report reply latency p50 / p99 in the test log.
5. **Stall injection:** a deliberately blocked ROS callback must not delay replies.

## Out of scope
Joint or Cartesian motion streaming, EKI, cameras.
