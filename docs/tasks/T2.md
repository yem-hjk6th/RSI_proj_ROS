# Task T2 (GitHub issue #2)

## Goal
Port the closed-loop control law to ROS 2 as a pure library plus a thin node, and prove it reproduces the logged lab run.

## Deliverables
- **`src/cl_controller`** (ament_python)
  - `cl_controller/law.py`: a port of `legacy/realtime_cl_261023/rt_law_v3.py`. Keep it pure: no ROS imports, no I/O.
  - The controller layer from `rt_controller.py`:
    - source selection (ELP → bore1 → model);
    - feed-forward;
    - speed floor;
    - leg-1 stop rule;
    - print window.
  - A node that subscribes to `/width/elp`, `/width/bore1` and `/krc/state`, and publishes `/krc/override_cmd`.
  - Every parameter the legacy CLI exposes (the `run_cl.py` arguments) becomes a ROS parameter with the same default.
- **`config/e1.yaml`**: the parameter set E1 ran with. Recover it from:
  - `data/e1_20261022_165128/session_meta.json`;
  - `eval_v3_*.json`;
  - the `ctrl_*.csv.gz` header;
  - the `run_cl.py` defaults.

## Acceptance tests (pytest)
1. **Golden replay.**
   - Inputs: E1's logged widths (`readout_*.csv.gz`, `bore1_rt_*.csv.gz` / `fusion_*.csv.gz`) and RSI state (`rsi_data_*.csv.gz`), fed into the ported law in logged order.
   - Expected: the logged controller updates (`ctrl_*.csv.gz`) and the override sequence (`ov_cmd_*.csv.gz`).
   - Integer OvCmd must match exactly; floats within a stated tolerance.
   - If an exact match is impossible (e.g. because of thread timing), explain why in the PR and quantify the mismatch.
2. **Differential unit tests.** Run the legacy `rt_law_v3.Law` and the port on the same synthetic sequences and compare their outputs.
3. **Legacy behaviour.** The speed floor and the leg-1 stop rule behave as in legacy.

## Out of scope
- RSI networking (the `krc_rsi_bridge` issue).
- Image processing.
